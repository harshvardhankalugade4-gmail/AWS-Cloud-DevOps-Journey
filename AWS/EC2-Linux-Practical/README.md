# AWS EC2 Linux Practical

## Overview

Hands-on practice of Linux on an AWS EC2 instance.

## Practical Tasks

- Launched an AWS EC2 Linux instance
- Connected to the server using SSH
- Practiced Linux file and directory management
- Created and edited files using Vim
- Created and edited files using Nano
- Copied files using `cp`
- Created a backup directory
- Verified files and backup

## Tools Used

- AWS EC2
- Linux
- Git Bash
- Vim
- Nano
- SSH

## Learning Outcome

This practical helped me understand Linux file management and text editors while working on an AWS EC2 server.
